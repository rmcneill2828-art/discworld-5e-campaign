# Campaign Log

The working memory for this campaign. Every other file in this repo is prep material — this is the one that changes. Update it at the end of every session (or the start of the next) so continuity survives between conversations.

**How to use this file:**
- Keep entries short and factual. This is a working reference, not prose to be proud of.
- Update the standing tables and Established Canon *as things happen*, not just in the session log — those sections are what gets checked mid-scene.
- Never delete a Session Log entry. Correct forward, the way the Disc's own geography does.
- If something here contradicts one of the published companion docs (Charter, Gazetteer, Names Worth Knowing), **this file wins** — it's what actually happened at this table.
