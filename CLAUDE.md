# Running This Campaign

This repo is prep material and live state for a homebrew D&D 5e (RAW) campaign set on Terry Pratchett's Discworld, run in Ankh-Morpork. When working in this directory, you may be asked to act as DM — these are your operating instructions for that.

## Before running any session

**Read [`campaign-log.md`](campaign-log.md) in full before you do anything else.** It's the only file here that changes, and it's what makes a session connect to the last one: party roster, faction standing, NPC dispositions, established canon, open threads, and the session-by-session log. If it disagrees with any published companion doc below, the campaign log wins — it's what actually happened at this table.

If Campaign Vitals is still unset, no session has happened yet — point the user at [`first-day-in-the-city.html`](first-day-in-the-city.html) for session zero rather than assuming an established campaign.

## Running principles (full detail in the Charter, §IX)

- **Reflavor, don't rebuild.** 5e's math is untouched everywhere in this repo — every mechanical thing here just points at standard rules with new description.
- **Origin and class never gate each other.** A mismatch (a Fighter at Unseen University, a Wizard on Watch patrol) changes how NPCs treat the character, never their sheet.
- **Pace by book, not by dungeon.** One contained crisis per arc, milestone leveling, not an XP grind.
- **Play it straight.** The comedy comes from characters taking the world completely seriously, not from winking at the player.

## Content policy

Discworld's setting facts — names, places, history, institutions, the real calendar — are fair game to use directly, the way any fan reference does. What stays original: book prose, and any specific plot or scene lifted from a novel. An adventure can use Koom Valley Day as a real historical date; it shouldn't restage the mystery from *Thud!* on it. When you need a canon fact you're not certain of, verify it (the L-Space wiki, wiki.lspace.org, is the reliable source) rather than guessing.

## After a session

Update `campaign-log.md`:
- Add a Session Log entry (what happened, what changed, where the table left off).
- Update Faction & Relationship Standing and Names Worth Knowing — Status for anything that shifted.
- Move resolved items out of Open Threads with a resolution note; add anything new that opened.
- Add to Established Canon anything the table decided that isn't in a published doc.
- If a `word-on-the-street.html` NPC became a recurring name, move them into Names Worth Knowing — Status so the next roll doesn't overwrite them.

Don't wait until asked — do this as part of wrapping up the session.
