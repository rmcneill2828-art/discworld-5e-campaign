# Discworld 5e Campaign

Homebrew reference material for running a Dungeons & Dragons 5th Edition (rules-as-written) campaign set on Terry Pratchett's Discworld.

This repo contains original game-prep material only (setting primers, character options, adventure notes) — no book text, no copyrighted Pratchett content.

## Contents

- [`discworld-charter.html`](discworld-charter.html) — campaign setting primer: cosmology, geography, guilds & factions, magic systems, playable peoples, the Guild/Watch/Civilian origin system, class mapping, and adventure hooks. Also published as a [Claude Artifact](https://claude.ai/code/artifact/e274a93a-d0e7-4a77-9f98-173a41dbd61d).

## Status

Living document — expect additions (player character options, subclasses, one-shots) over time.
